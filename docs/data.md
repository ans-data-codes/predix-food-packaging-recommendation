# Data Strategy

## Data Categories

1. Food-property and commodity descriptors
2. Storage and transport condition data
3. Packaging-material performance data
4. Domain knowledge and literature-derived guidance
5. Future training/evaluation datasets

## Source-Derived vs Synthetic vs Model-Derived

- **Source-derived data:** Values backed by verified literature, standards, supplier datasheets, or laboratory reports.
- **Synthetic prototype data:** Non-authoritative sample data used only for workflow and UI demonstration.
- **Model-derived predictions:** Outputs from trained models; these require validated training data and calibration.

## Data Governance Notes

- No classified or private data should be used.
- Scientific values must be source-backed before production use.
- Prototype outputs are not production decisions.
