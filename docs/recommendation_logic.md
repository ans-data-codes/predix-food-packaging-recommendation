# Recommendation Logic

## Hybrid Decision Framework

Rule Layer + ML Ranking + Multi-Criteria Scoring -> Final Recommendation

## Layer Responsibilities

- **Rule Layer:** Feasibility and compatibility gating.
- **ML Ranking:** Prioritization of feasible candidates after rules are applied.
- **Multi-Criteria Scoring:** Final score composition across barrier, shelf-life, mechanical, cost, and sustainability criteria via configurable weights.

## Explainability and Confidence

Every recommendation should provide rationale, warnings, alternatives, and separately tracked confidence information.
